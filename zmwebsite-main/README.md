# ZM Printing & Embroidery - Official Website

Modern, responsive web application for ZM Printing & Embroidery factory profile, services, machinery, certifications, and client portfolio.

---

## 🚀 Quick Start for Windows (One-Click)

### 1. Run Website on Localhost
Double-click `1_RUN_LOCALHOST.bat`
- Automatically checks for Node.js and dependencies.
- Installs packages (`npm install`) if not present.
- Launches Vite local server and opens your browser at `http://localhost:5173`.

### 2. Build for Production / Live Deployment
Double-click `2_BUILD_PRODUCTION_DIST.bat`
- Runs code error checking and linting.
- Generates production-ready static files in the `dist/` directory.
- Opens the `dist/` folder in File Explorer for easy upload to cPanel (`public_html`) or hosting servers.

---

## 🛠 Manual Commands (CLI)

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run linting check
npm run lint

# Build production bundle
npm run build

# Preview production build locally
npm run preview
```

- **Linter:** Oxlint
